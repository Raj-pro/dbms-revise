1. What is a primary key?

A primary key is the candidate key selected to identify each row in a table. Its values must be unique and cannot be NULL.

Unique

Two rows cannot have the same primary-key value.

Not NULL

Every row must have a primary-key value.

Remember: A table has only one primary-key constraint, but that key may contain multiple columns (a composite primary key).

4. Simple vs composite primary key

Simple primary key

Uses one attribute.

STUDENT(StudentID, Name)

PK: StudentID

Composite primary key

Uses two or more attributes together.

ENROLLMENT(StudentID, CourseID)

PK: (StudentID, CourseID)

The same student can take many courses, and each course can have many students; the pair identifies an enrolment.
