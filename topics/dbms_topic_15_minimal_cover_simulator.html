Equivalent FD Sets & Minimal Cover

Learn when two FD sets mean the same thing and how to simplify dependencies without changing their meaning.

1. Equivalent functional dependency sets

Two FD sets F and G are equivalent when each set implies every dependency in the other. In closure notation, they have the same implied dependencies.

F and G are equivalent if F⁺ = G⁺

Practical test: every FD in F must follow from G, and every FD in G must follow from F. We often use attribute closure to test whether an FD follows.

Example: F = {A → B, B → C}; G = {A → B, B → C, A → C}. These are equivalent because A → C is already implied by transitivity.

2. What is a minimal cover?

A minimal cover (also called canonical cover in many courses) is a simplified FD set that is equivalent to the original set and has no unnecessary parts.

Usually, we require:

  1. Each FD has a single attribute on its right side.
  2. No extraneous attribute on any left side.
  3. No FD can be removed without changing the implied dependencies.

3. The three simplification steps

Step 1 — Split RHS: A → BC becomes A → B and A → C.
Step 2 — Remove extraneous LHS attributes: if an attribute on the left can be removed while preserving the FD, remove it.
Step 3 — Remove redundant FDs: if the remaining FDs can still derive one FD, remove that FD.

4. Worked example

Find a minimal cover for:

F = { A → BC, B → C, A → B }
1. Split A → BC into A → B and A → C.
2. The set is now {A → B, A → C, B → C, A → B}.
3. Remove duplicate A → B.
4. A → C is redundant because A → B and B → C imply A → C by transitivity.
Minimal cover = { A → B, B → C }
Equivalent, with no redundant FD

7. Practice questions

Q1. What must be true for F and G to be equivalent?
Q2. Why split A → BC when making a minimal cover?
Q3. Given A → B and B → C, is A → C redundant if it is also listed?

Exam checklist

  1. Split every right side into single attributes.
  2. Check for extraneous attributes on the left.
  3. Check whether each FD is implied by the others; remove redundant ones.
  4. Verify the simplified set is equivalent to the original.
