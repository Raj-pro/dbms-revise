Procedural vs Non-procedural Query Languages

Understand whether you specify the steps to retrieve data or simply describe the data you want.

1. The core difference

Procedural

What to do + how to do it

You specify the operations or sequence of steps to obtain the result.

Example: Relational Algebra.

Non-procedural (declarative)

What result you want

You describe the required data; the database system decides how to retrieve it.

Example: SQL is largely declarative; Tuple and Domain Relational Calculus are non-procedural.

2. Same task, two styles

Task: find the names of students who belong to the CSE department.

Relational Algebra (procedural)

First select CSE students, then project their names:

πName(σDept='CSE'(STUDENT))

The expression shows the operations: select rows, then project a column.

SQL (declarative)

SELECT Name
FROM STUDENT
WHERE Dept = 'CSE';

You specify the desired rows and columns; the query optimizer chooses an execution plan.
