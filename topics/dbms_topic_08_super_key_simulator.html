Super Key — Interactive Simulator

Discover why every candidate key is a superkey, but not every superkey is a candidate key.

1. What is a superkey?

A superkey is any set of one or more attributes that uniquely identifies every row in a relation.

Superkey

Must uniquely identify each row. It may contain extra attributes that are not needed.

Candidate key

A minimal superkey: it uniquely identifies rows, and no attribute can be removed without losing uniqueness.

Memory rule: Every candidate key is a superkey. A superkey with unnecessary extra attributes is not a candidate key.
