Attribute Closure (X⁺)

Find every attribute that a set of attributes can determine using functional dependencies.

1. What is attribute closure?

The closure of X, written X⁺, is the set of all attributes that can be derived from X using the given functional dependencies.

X⁺ = all attributes determined by X

We use closure to check whether X is a superkey or a candidate key.

Rule: Start with X. Repeatedly apply any FD whose left side is already contained in the current set. Add its right-side attributes. Stop when no new attributes can be added.

2. Worked example

Relation: R(A, B, C, D, E)

Functional dependencies:

  • A → B
  • B → C
  • AC → D
  • D → E

Find A⁺.

Start: A⁺ = {A}
A → B, add B: {A, B}
B → C, add C: {A, B, C}
AC → D, since A and C are present, add D.
D → E, add E.
A⁺ = {A, B, C, D, E}
A is a superkey for this relation

3. Superkey or candidate key?

Compare closure with all attributes in the relation.

  • If X⁺ contains every attribute, X is a superkey.
  • If X is a superkey and no proper subset of X is a superkey, X is a candidate key.
Example: If AB⁺ = {A, B, C, D}, AB is a superkey for R(A,B,C,D). To call it a candidate key, also check whether A⁺ or B⁺ already contains all attributes.

6. Exam method

  1. Write the starting set X.
  2. Scan the FDs and check whether each left side is contained in your current set.
  3. Add the right side whenever possible.
  4. Repeat the scan until the set stops growing.
  5. Compare X⁺ with the relation's attributes to test for a superkey.
  6. For a candidate key, test minimality by checking proper subsets.
