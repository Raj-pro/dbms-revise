Concurrency Control

How a DBMS lets multiple transactions work at the same time without corrupting data.

1. What problem does it solve?

Concurrency means multiple transactions overlap in time. This improves performance, but careless interleaving can cause incorrect results. Concurrency control coordinates their operations so database consistency is preserved.

Lost update

Two transactions update the same value; one update overwrites the other.

Dirty read

A transaction reads another transaction’s uncommitted change.

Unrepeatable read

A transaction reads the same row twice and gets different values because another transaction committed an update in between.

2. Try the lost-update problem

Suppose account balance X starts at ₹100. T1 adds ₹20 and T2 adds ₹10. If each reads the old value before either writes, one update may be lost.

Transaction T1: add ₹20
R1(X) → calculate 100 + 20
W1(X)
Transaction T2: add ₹10
R2(X) → calculate 100 + 10
W2(X)
Initial balance: ₹100. Correct final balance after both updates: ₹130.

3. Common approaches

TechniqueSimple explanationKey idea
Lock-based controlA transaction locks data before using it.Shared lock (S) for reading; exclusive lock (X) for writing.
Two-Phase Locking (2PL)First acquire locks, then release them; after releasing begins, it cannot acquire new locks.Growing phase → shrinking phase.
Timestamp orderingOperations must respect transaction timestamps.Older/younger transaction order governs conflicts.
Optimistic controlTransactions work first, then validate before committing.Read → validate → write.
MVCCKeep multiple versions of data so readers can often see a consistent snapshot.Readers and writers may interfere less.

4. Lock compatibility

A shared lock permits reading. An exclusive lock is needed to write.

Two shared locks can coexist. An exclusive lock conflicts with every other lock on that item.

Exam recap

  • Concurrency control coordinates overlapping transactions.
  • Common anomalies include lost updates, dirty reads, and unrepeatable reads.
  • Locks, 2PL, timestamp ordering, optimistic control, and MVCC are major techniques.
  • Basic 2PL has a growing phase and a shrinking phase.
