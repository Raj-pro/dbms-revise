Relational Calculus

Describe the data you want using logical conditions instead of a sequence of operations.

1. What is Relational Calculus?

Relational Calculus is a non-procedural query language. It specifies what tuples or values should appear in the answer, rather than prescribing how to compute them.

Relational Algebra: how to query · Relational Calculus: what result satisfies a condition

Tuple Relational Calculus (TRC)

Uses variables that represent entire tuples (rows).

{ t | STUDENT(t) ∧ t.Dept = 'CSE' }

Read it as: “the tuples t from STUDENT whose department is CSE.”

Domain Relational Calculus (DRC)

Uses variables that represent individual attribute values, rather than whole rows.

{ ⟨n⟩ | ∃id, d, y (STUDENT(id,n,d,y) ∧ d='CSE') }

Read it as: “the names n of students whose department value d is CSE.”

Free and bound variables

Free variable: not controlled by a quantifier in the formula; it represents output or otherwise remains free.

Bound variable: controlled by a quantifier such as ∃ (there exists) or ∀ (for all).

In {t | STUDENT(t) ∧ t.Dept='CSE'}, t is free in the condition/result expression.

Safe vs unsafe queries

A query is safe when its result is finite and drawn from the active domain (values present in the database, under the standard safe-calculus interpretation).

An unsafe query may describe an infinite result or include values unrelated to the database.

Example idea: “all integers x such that x=x” is unsafe over an infinite integer domain.
