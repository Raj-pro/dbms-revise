Armstrong’s Axioms and Derived Rules

Learn how to derive new functional dependencies from the ones you already know.

What are Armstrong’s axioms?

They are sound and complete inference rules for functional dependencies. In simple terms, they tell us which new dependencies logically follow from known dependencies.

Given FDs → Apply a rule → Derive another FD

The three basic axioms are Reflexivity, Augmentation, and Transitivity. Union, Decomposition, and Pseudotransitivity are commonly used derived rules.

1. Reflexivity

If Y ⊆ X, then X → Y

If the right-side attributes are already included on the left, the dependency must hold.

Example: {StudentID, CourseID} → StudentID
Subset rule

2. Augmentation

If X → Y, then XZ → YZ

Add the same attribute set Z to both sides of a valid FD.

Example: A → B gives AC → BC.
Add the same attributes to both sides

3. Transitivity

If X → Y and Y → Z, then X → Z

If X determines Y, and Y determines Z, then X determines Z.

Example: StudentID → DeptID and DeptID → DeptName, so StudentID → DeptName.
Chain rule

4. Union

If X → Y and X → Z, then X → YZ

Combine two dependencies with the same left side.

Example: A → B and A → C give A → BC.
Combine right sides

5. Decomposition

If X → YZ, then X → Y and X → Z

Split a dependency with multiple attributes on the right into separate dependencies.

Example: A → BC gives A → B and A → C.
Split right sides

6. Pseudotransitivity

If X → Y and WY → Z, then WX → Z

Use X to obtain Y; together with W, that gives WY, which determines Z.

Example: A → B and CB → D, so CA → D.
Chain with extra attributes
