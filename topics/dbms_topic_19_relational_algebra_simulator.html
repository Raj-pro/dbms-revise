Relational Algebra

Explore the fundamental operations used to query relational tables.

1. What is Relational Algebra?

Relational Algebra is a procedural query language: it describes operations that transform relations (tables) into new relations. Each operation takes relation(s) as input and returns a relation as output.

Input relation(s) → Operation → Result relation

Selection (σ)

Chooses rows that satisfy a condition.

σDept='CSE'(STUDENT)
Rows

Projection (π)

Chooses columns. In classical relational algebra, duplicate result tuples are removed.

πName(STUDENT)
Columns

Rename (ρ)

Renames a relation or its attributes.

ρS(STUDENT)
Names

Union (∪)

Returns tuples in either relation. The relations must be union-compatible.

R ∪ S
Either set

Set Difference (−)

Returns tuples in R that are not in S. Relations must be union-compatible.

R − S
R only

Intersection (∩)

Returns tuples common to both union-compatible relations.

R ∩ S
Both sets

Cartesian Product (×)

Combines every tuple in R with every tuple in S. If R has m rows and S has n rows, result has m × n rows (before any duplicate considerations).

R × S

Join (⋈)

Combines related tuples from two relations using a condition. Natural join matches same-named attributes and removes the duplicate join column.

R ⋈ S

Division (÷)

Useful for “for all” queries: find values related to every value in another relation.

ENROLLED(Student, Course) ÷ REQUIRED(Course)

Returns students enrolled in every required course.

3. Join types

Theta / Conditional join

Join using any condition such as R.A > S.B or R.id = S.id.

Natural join

Automatically matches all same-named attributes and keeps one copy of each join attribute.

Left outer join

Keeps every row from the left relation; unmatched right-side values are null.

Right outer join

Keeps every row from the right relation.

Full outer join

Keeps matched rows and all unmatched rows from both relations.
