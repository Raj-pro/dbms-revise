Data Types — Interactive Simulator

Learn how a column's data type controls what kind of value it can store.

1. The idea in simple words

A data type tells the database what kind of value a column is designed to hold. Think of it as a rule for each column: age stores whole numbers, name stores text, and joining date stores a date.

INT / INTEGER: Stores whole numbers such as 0, 17, or -4. A value like 17.5 is not an integer.

Note: Exact names and rules vary by database system (MySQL, PostgreSQL, SQL Server, etc.).
