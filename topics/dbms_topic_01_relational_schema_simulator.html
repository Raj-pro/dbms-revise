Relational Schema — Interactive Simulator

Understand how a database table is designed before storing its rows.

1. The idea in simple words

A relational schema is the blueprint of a table. It tells us the table's name and the attributes (columns) it contains. The actual data rows are called the table's instance or contents.

Schema = DesignSTUDENT(StudentID, Name, Department)
Attributes = Columns

StudentID, Name, Department

Instance = Data

The actual students stored in the table.
