Foreign Key — Interactive Simulator

See how one table refers to a row in another table.

1. What is a foreign key?

A foreign key (FK) is a column, or group of columns, in one table whose values refer to a candidate key—usually the primary key—of another table (or sometimes the same table).

Parent table

DEPARTMENT(DeptID, DeptName)

DeptID is the primary key.

Child table

STUDENT(StudentID, Name, DeptID)

DeptID is a foreign key that refers to DEPARTMENT.

Memory trick: Primary key identifies a row in its own table; foreign key links a row to a key in a referenced table.
