Candidate Key — Interactive Simulator

Find the smallest set of columns that uniquely identifies every row.

1. Candidate key in simple language

A candidate key is a column, or a combination of columns, that can uniquely identify every row in a table. It must satisfy two rules:

① Uniqueness

Two different rows cannot have the same value for the chosen key.

② Minimality

No column can be removed from the key while keeping it unique.

Memory trick: Candidate key = unique + minimal. A key can be one column (simple) or multiple columns (composite).

2. Watch a simple candidate key

StudentID uniquely identifies each student, so it can be a simple candidate key.

StudentIDNameEmail
101 🔑Ashaasha@example.com
102 🔑Raviravi@example.com
103 🔑Meerameera@example.com

Why? Each StudentID is different, and StudentID alone is enough. It is a one-attribute (simple) candidate key.
